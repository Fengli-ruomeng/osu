# Welcome to the KaguyaOSU Practice Version!

This is a custom modified version based on osu!lazer.

Please note that this is **not** an official version from peppy.

This version will not submit any pull requests to osu!lazer for merging these features. Instead, this project exists as my own relatively aggressive custom revision, mainly for adding special features that I personally want to experiment with.

It will include many features designed for practice, retrying specific details, analysis, entertainment, and addressing certain pain points. Some features may also be added simply because I think they would be interesting.

## Important Notice

This project currently does **not** synchronize any online content.

This means that I will not take responsibility for any issues that may occur if you decide to use it online.

This is intended to be a purely offline client — and you are strongly encouraged to use it that way.

However, this may not be permanent. In the future, I may try to make certain adjustments so that it can safely connect to BanchoNet.

## About This README

This is currently a very simple README, and I may add more updates to it in the future.

I will try to regularly sync with the upstream project and maintain a certain update frequency.

I hope this can become my own version of **McOsu**!

Any suggestions for my special version are welcome — or just have fun playing it. ^_^
